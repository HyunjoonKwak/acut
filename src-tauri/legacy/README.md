# legacy — v1 코드

에이컷 v1(«스마트 폴더» 시절)의 Rust·프론트 코드다. **빌드에 들어가지 않는다.**
지우지 않고 여기 두는 이유: 다시 쓸 만한 조각(폴더 감시 `core/watcher.rs`,
앨범 `commands/albums.rs`)이 있고, v2가
실사용으로 검증될 때까지 대조할 수 있어야 한다.

`commands/update.rs`의 v1 직접 다운로드 명령은 안전을 위해 비활성화했다. 업데이트
기능은 이 코드를 재사용하지 말고 v2처럼 공식 릴리스 페이지 열기와 서명·공증 검증을
거쳐야 한다.

v2로 가져간 것: `core/sync.rs`·`core/hasher`(로컬 백업용), `nas/`(올리기용),
`cull/`(고르기). 나머지는 여기.

2026-08-27 사용자 결정으로 격리. 자세한 순서는 로드맵 메모리 참조.
