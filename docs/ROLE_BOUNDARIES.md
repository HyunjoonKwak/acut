# 사진 시스템 역할 경계

이 문서는 Photo Backup, Photo Desk, Photo Gallery 사이의 운영 책임을 고정한다.
새 기능과 운영 변경은 아래 경계를 기본값으로 삼는다.

| 구성요소 | 정본 역할 | 하지 않는 일 |
|---|---|---|
| Photo Backup | 카드·기기·외부 원본의 안전한 수집과 보관 | 원본 정리 규칙 결정, Gallery 큐레이션 |
| Photo Desk | 물리 파일 정리, 촬영일·메타데이터 교정, 내사진·공용 배포의 정본 | 감상 서비스 운영, Gallery 운영 설정 변경 |
| Photo Gallery | 읽기 중심 감상, 앨범·인물 등 논리적 큐레이션 | 원본 파일 이동·이름 변경·메타데이터 교정 |

## 경계를 넘는 요청

향후 요구가 둘 이상의 역할을 섞거나 기존 정본을 옮기려면 구현 전에 멈춘다.
다음 내용을 사용자에게 먼저 제시하고 명시적인 결정을 받은 뒤 진행한다.

1. 영향을 받는 데이터·앱·운영 경로
2. 정본과 책임이 어떻게 바뀌는지
3. 가능한 선택지와 각 선택지의 롤백 방법
4. 기존 자동화·배포·읽기 전용 경계에 미치는 영향

Photo Desk 작업은 Photo Gallery 저장소와 Gallery/NAS 운영 설정을 직접 변경하지
않는다. 실제 사용자 사진을 대상으로 하는 이동·삭제·메타데이터 변경 검증은 별도
승인 없이는 하지 않으며, fixture·복사 표본·dry-run을 기본으로 한다.
